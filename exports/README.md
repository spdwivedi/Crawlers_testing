# Standalone Scraper Packages & Data Lake Exports (`exports/`)

The `exports/` directory serves as the delivery and deployment staging area for zero-monorepo dependency packages, cryptographically signed Data Lake archives, and containerized microservice pipelines generated by `core/project_exporter.py`.

---

## 📂 Export Directory Hierarchy

```
exports/
├── standalone_tools/    # Zero-monorepo runnable scraper projects
│   ├── <tool_id>_standalone/
│   │   ├── run.py                 # Standalone CLI entrypoint
│   │   ├── adapter.py             # Sanitized scraper adapter (imports compat.py)
│   │   ├── compat.py              # Zero-dependency monorepo compatibility shim
│   │   ├── config.json            # Engine execution parameters
│   │   ├── requirements.txt       # Engine-specific dependencies only
│   │   ├── README.md              # Standalone usage and deployment runbook
│   │   └── export_manifest.json   # Cryptographic SHA-256 file catalog
│   └── <tool_id>_standalone.zip   # Compressed distribution archive
│
├── data_bundles/        # Signed Data Lake Silver/Bronze deliverables
│   ├── data_bundle_<scope>_<timestamp>.zip       # Compressed archive
│   └── data_bundle_<scope>_<timestamp>_manifest.json # Provenance manifest
│
└── pipeline_packages/   # Production pipeline microservice containers
    └── <pipeline_id>_pkg/
        ├── pipeline_runner.py     # Standalone pipeline CLI runner
        ├── pipeline.py            # Sanitized pipeline logic
        ├── compat.py              # Zero-dependency compatibility shim
        ├── requirements.txt       # Pinned production requirements
        ├── Dockerfile             # Container image definition (Python 3.11-slim)
        ├── README.md              # Container deployment guide
        └── export_manifest.json   # Package integrity manifest
```

---

## 🔒 Zero-Leak Security Filtering

All packages and archives built via `core/project_exporter.py` strictly enforce the Zero-Leak security protocol:
- **Blocked Extensions:** `.env`, `.sqlite`, `.sqlite3`, `.db`, `.key`, `.pem`, `.p12`, `.pfx`, `.crt`, `.cert` are never included.
- **Blocked Paths:** Any path containing `temp_cookies`, `vault_store`, `secrets`, `.git`, or `__pycache__` is blocked.
- **Git Tracking Rules:** As specified in `.gitignore`, all `.zip` and `.tar.gz` files remain untracked locally, while all `export_manifest.json` and `.gitkeep` files are tracked for reproducibility.

## 🚀 Execution & Deployment Runbook

### 1. Running an Exported Standalone Scraper
```bash
cd exports/standalone_tools/01_curl_cffi_standalone/
pip install -r requirements.txt
python run.py --url "https://quotes.toscrape.com"
python run.py --url "https://quotes.toscrape.com" --human-mode --timing-profile BALANCED_HUMAN
```

### 2. Building & Running Dockerized Pipeline Containers
```bash
cd exports/pipeline_packages/01_leetcode_archiver_pkg/
docker build -t leetcode-archiver:latest .
docker run --rm leetcode-archiver:latest --target "two-sum"
docker run --rm leetcode-archiver:latest --mock
```

### 3. Downloading via Control Center API
Exported archives can be downloaded directly from the Control Center UI (Tab 8) or via REST:
```bash
curl -O http://127.0.0.1:8000/api/exports/download/data_bundles/data_bundle_cleaned_latest.zip
```
